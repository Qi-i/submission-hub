# Submission Hub UI 几何一致性合同

本文件定义所有后续 UI 修改必须同时满足的硬性约束。任何功能开发、主题调整或局部修复都不得破坏这些规则。

## 1. 统一水平基准

- 顶部主菜单栏、Luminous X 状态栏、页面子菜单、统计卡片区、内容网格、期刊中心、投稿准备、个人统计和后台管理必须共享同一组左右边界。
- 桌面端统一最大宽度：`1440px`。
- 页面水平边距统一使用 `--ui-shell-gutter`，禁止在单独页面写入不同的 `margin-left`、`padding-inline` 或 `max-width`。
- 新增页面或模块必须优先接入 `.app-layout` 顶层宽度合同，不得自行创建另一套页面容器宽度。

## 2. 圆角分级

- 页面外壳：`16px`。
- 内容卡片和主要面板：`14px`。
- 菜单、搜索框和操作组：`10px`。
- 菜单按钮与小型控件：`8px`。
- 同一层级不得混用不同圆角；不得为单个页面或单个按钮临时增加例外圆角。

## 3. 间距节奏

- 顶层页面模块间距统一为 `12px`。
- 同一网格内的行间距和列间距统一为 `12px`。
- 主菜单与下一层状态栏或内容区域之间必须使用同一间距。
- 禁止使用固定高度、绝对定位或空白占位来“凑齐”对齐；内容应按正常文档流排列。

## 4. 菜单一致性

- 主菜单、投稿准备子菜单、Luminous X 代理菜单和个人统计模块菜单使用同一控件高度与圆角尺度。
- 同一功能只能有一个可见入口。期刊中心为期刊库唯一主入口；投稿准备中仅保留总览里的期刊概览模块，不重复显示“期刊库”子菜单。
- 所有主题、亮暗模式、在线版和离线版必须同步检查。

## 5. 期刊中心数据语义

- 期刊中心是完整期刊档案库，不是“收藏夹”。
- 手动新增、投稿历史自动收录和重点期刊均属于期刊中心记录。
- `is_favorite` 仅表示“重点期刊”，不得决定记录是否进入期刊中心。
- 有正式投稿历史但尚无期刊档案时，系统自动建立普通简易记录；用户可继续补充信息或设为重点期刊。
- 操作名称统一使用“新增期刊”“期刊档案”“重点期刊”“普通记录”，不再使用“收藏期刊”作为期刊库总称。

## 6. 强制回归检查

每次涉及 UI、导航、页面容器或期刊中心的修改，至少验证：

1. 顶部主菜单与页面内容左右边界误差不超过 `2px`；
2. 顶层相邻模块间距差异不超过 `6px`；
3. 同层菜单按钮高度差异不超过 `3px`；
4. 菜单圆角在 `7–11px`，内容面板圆角在 `12–16px`；
5. 投稿准备中不存在重复的期刊库入口；
6. 页面不再外显“收藏期刊”旧术语；
7. Luminous、Luminous X、亮色、暗色和移动端均无横向溢出。

上述规则由 `.github/workflows/ui-contract.yml` 和 `tests/visual/ui-geometry-contract-check.mjs` 自动检查。CI 未通过时不得合并发布。
