# Submission Hub UI 几何与材质一致性合同

本文件定义所有后续 UI 修改必须同时满足的硬性约束。任何功能开发、主题调整或局部修复都不得破坏这些规则。

## 1. 两套布局模型，分别统一

- **Luminous 标准视图**采用顶部主菜单：主菜单、页面工具、子菜单、统计区和内容网格必须共享同一组左右边界，桌面端最大宽度为 `1440px`。
- **Luminous X 桌面视图**采用固定左侧栏：侧栏保持独立固定宽度，状态栏、页面工具和内容网格共享右侧内容轨道的左右边界。禁止把顶部栏宽度规则直接套用到侧栏。
- Luminous X 在 `980px` 以下转换为顶部菜单，此时顶部菜单和内容恢复同一水平基准。
- 页面水平边距统一使用主题对应的壳层变量，禁止在单独页面临时写入不同的 `margin-left`、`padding-inline` 或 `max-width`。
- 新增页面或模块必须接入当前主题的既有布局模型，不得创建第三套页面容器宽度。

## 2. 圆角分级

- 标准页面外壳：`16px`；Luminous X 桌面侧栏保留其独立外壳圆角。
- 内容卡片和主要面板：`14px`。
- 菜单、搜索框和操作组：`10px`。
- 菜单按钮与小型控件：`8px`。
- 同一层级不得混用不同圆角；不得为单个页面或单个按钮临时增加例外圆角。

## 3. 间距节奏

- 顶层页面模块间距统一为 `12px`。
- 同一网格内的行间距和列间距统一为 `12px`。
- Luminous 顶部主菜单与下一层内容、Luminous X 状态栏与内容区，分别使用本布局模型的统一节奏。
- 禁止使用固定高度、绝对定位或空白占位来“凑齐”对齐；内容应按正常文档流排列。

## 4. 菜单一致性

- 同一菜单组内的按钮高度差异不得超过 `3px`；不同布局层级可保留既有尺寸等级，例如 Luminous X 侧栏主菜单与内容代理菜单不强制等高。
- 同一功能只能有一个可见入口。期刊中心为期刊库唯一主入口；投稿准备中仅保留总览里的期刊概览模块，不重复显示“期刊库”子菜单。
- “期刊中心”必须具有与其他一级菜单一致的完整色块、边框、悬停态和激活态，不得退化为透明文字按钮。
- 所有主题、亮暗模式、在线版和离线版必须同步检查。

## 5. 期刊中心数据语义

- 期刊中心是完整期刊档案库，不是“收藏夹”。
- 手动新增、投稿历史自动收录和重点期刊均属于期刊中心记录，默认筛选必须为“全部”。
- `is_favorite` 仅表示“重点期刊”，不得决定记录是否进入期刊中心。
- 有正式投稿历史但尚无期刊档案时，系统自动建立普通简易记录；用户可继续补充信息或设为重点期刊。
- 自动记录必须在界面中明确标记为“投稿自动收录”，并可按“全部、重点期刊、投稿自动收录、手动记录”筛选。
- 操作名称统一使用“新增期刊”“期刊档案”“重点期刊”“普通记录”，不再使用“收藏期刊”作为期刊库总称。

## 6. 空间玻璃材质合同

- 材质升级只作用于背景、透明度、模糊、边框高光和阴影，不改变既有布局、模块尺寸、内容顺序或业务逻辑。
- 背景使用大范围、低透明度的青、紫、蓝绿色场，不使用独立霓虹光球、强烈炫光或营销页式装饰。
- 主要面板使用克制的半透明表面、细边框和单层柔和阴影；不得通过多层厚重阴影降低信息密度。
- 背景呼吸仅允许缓慢改变背景位置或阴影强度，不允许缩放、位移内容卡片或造成文字抖动。
- 系统启用 `prefers-reduced-motion: reduce` 时必须停用呼吸动画。

## 7. 深色生产力模式

- 深色模式首先满足阅读与录入效率，不以“氛围感”牺牲文字对比度。
- 主文字、标题和输入内容使用高亮中性色；辅助文字不得低于清晰可读的灰蓝层级，禁止依赖低透明度表达主次。
- 输入框、下拉框、按钮、链接、标签和表格必须有清晰边界；悬停与聚焦状态必须可辨认。
- 暗色卡片和页面背景需保持足够明度差，不能使用近似黑色叠加导致模块边界消失。
- 状态、分区和警示色保持低饱和但必须具备明确的文字与底色对比。

## 8. 强制回归检查

每次涉及 UI、导航、页面容器或期刊中心的修改，至少验证：

1. Luminous 顶部主菜单与内容左右边界误差不超过 `2px`；
2. Luminous X 侧栏宽度保持在既定范围，且侧栏与右侧内容轨道之间无重叠；
3. Luminous X 状态栏和页面内容左右边界误差不超过 `2px`；
4. 顶层模块使用统一间距，同层菜单按钮高度差异不超过 `3px`；
5. 菜单圆角在 `7–11px`，内容面板圆角在 `12–16px`；
6. 投稿准备中不存在重复的期刊库入口，页面不再外显“收藏期刊”旧术语；
7. 期刊中心默认展示全部记录，并能区分重点、自动收录和手动记录；
8. “期刊中心”一级菜单在亮色和暗色下均具有非透明色块；
9. 暗色标题、辅助文字、输入框和按钮达到可读对比，且不出现近黑模块粘连；
10. Luminous、Luminous X、亮色、暗色和移动端均无横向溢出；
11. 减少动态模式下背景和面板动画均停止。

上述规则由 `.github/workflows/ui-contract.yml`、`tests/visual/ui-geometry-contract-check.mjs` 及视觉回归任务自动检查。CI 未通过时不得合并发布。
