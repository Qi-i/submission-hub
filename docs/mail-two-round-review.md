# 邮件聚合：两轮第一性原则审查与修复记录

范围：Submission Hub Web、云端 IMAP/SMTP、邮件原文归档、动态 UI、GLM/自定义 AI 及 GitHub 发布链。版本保持 `v2.1.0`，只发布在线 Web，不创建 Release 或版本化下载资源。

## 第一轮：用户任务与端到端操作链

**核心目标：** 用户无需离开 Web 就能添加多个学校/个人邮箱、发现主机、手工修改端口和安全方式、保存授权、验证登录、归档、检索、发信以及按需分析。不是让用户编辑 GitHub 源码、运行 Python 或等待每次页面重构上线。

发现并修复：
- 邮件模块误嵌入投稿管理下的文字入口；改为第三个**一级菜单「邮件聚合」**，删除二级入口。
- 邮件页面最大宽度导致两侧留白；采用全站内容宽度，邮件列表及阅读区使用响应式双栏。
- 顶栏分散的设置、反馈及退出；集中到头像二级菜单。
- 投稿卡片期刊名被固定宽度、单行截断；改为独立行、两行适配、悬停全名，不触及期刊中心卡片逻辑。
- SMTP host 采用 IMAP 白名单而错误拒绝正常地址；取消错误的供应商硬编码，改为公网域名校验 + TLS 加密组合 + DNS SRV/预设候选。
- 收发信配置缺少端口、安全连接与独立登录名；Web 可分别编辑 IMAP/SMTP 993/143、465/587 和 SSL/STARTTLS。
- 保存配置被误当作“已经连接成功”；只有 IMAP 登录测试通过才激活云端轮询。
- GLM Key 已配置却无法验证，且模型/指令写死；增加 GLM 真实 API 探针、自定义兼容接口及单独 Vault 凭据、动态系统指令编辑。
- 审稿邀请频率低，不应占据常驻一级栏目；通过动态快捷视图按需启用。
- AI 自动分类与手工编辑冲突；AI 分类独立存为 `ai_category`，不覆盖手工分类，可联合检索。

## 第二轮：最小权限、计费边界、可恢复性与发布正确性

**核心目标：** 没有授权就不读/发邮件、不外传正文、不触发收费调用；可撤销密钥，识别失败不会伪报成功；发布只能更新网页而不能意外发布 GitHub Release。

发现并修复：
- 邮箱及模型自定义端点都限定公网 TLS；DNS 校验拒绝私有和保留 IP、直连 IP，API 不允许非 HTTPS、非 443 端口或跳转。
- IMAP 保持 `EXAMINE` + `BODY.PEEK[]` 的只读策略，不在服务器上标记已读、移动或删除；原文放私有 Storage。
- 自定义模型密钥仅在 Vault 内读写；删除接口时删除对应 Vault 密钥。
- GLM 免费预设不回退至付费模型；自定义模型如可能收费，要求接口级和全局两次授权，并设每日调用上限。
- AI 默认不开启，用户明确开启时记录起始时间；除非明确选择分析历史邮件，否则不会回填。
- 固定安全指令不能被网页配置或邮件正文覆盖；模型仅产生建议和索引。
- `public.mail_ai_endpoints`、`mail_preferences`、`mail_accounts` 有逐用户 RLS；`mail_private` 的无公开策略属于有意的私有设计。
- Release 工作流在 `main` 的 `package.json` 变动时会自动创建新 Release，因此**保持 package.json、package-lock 和版本元数据不变**。新增测试并入既有 `check:mail-center`，仅使用 Pages 部署。

## 验证与未覆盖边界

- `npm run verify`：原有模块合同测试、两轮邮件架构合同、TypeScript 和 Vite Web 构建必须全部通过。
- Edge Functions：已独立部署 `mail-config`、`mail-cloud-collector`、`mail-send`、`mail-ai-settings`、`mail-ai-analyze`。
- 云端调用：内部授权的 AI worker 返回 HTTP 200 且无待分析邮件时报告零调用；匿名邮件配置与 AI 密钥接口返回 HTTP 401。
- Supabase 安全审查：没有本轮新增的公开数据表安全告警；已有 Auth “泄露密码保护未启用”属于全站原有配置，本次不改账户认证。
- 邮件与 AI 模型的真实账号测试：必须在用户本人的网页登录态执行，无法用无人授权的 CI 替代；自动发现结果只是候选而非已证实服务器。
- 支持 IMAP/SMTP TLS；POP3、Gmail/Outlook OAuth2、HTML/附件发信仍不在本次已验证功能范围。
- 部署验收：以 GitHub Pages `build-info.json` 对照最终合并提交 SHA 为准。未核对 SHA 前不能宣称上线完成。

所有修复保持已有在线版号；**不新增 GitHub Release 或离线安装包**。
