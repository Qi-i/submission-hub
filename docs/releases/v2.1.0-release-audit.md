# v2.1.0 Release Audit

发布日期：2026-08-20

本文件记录 Submission Hub v2.1.0 的五轮发布审查。结论必须以 GitHub Actions、Release 和线上 SHA 的实际结果为准；尚未完成的检查不得提前标记为通过。

## 第一轮：架构

- FigMergeStudio 功能迁移为原生 React + TypeScript Figure Composer，不使用 iframe，也不复制独立 HTML。
- Figure Composer 拆分为 Canvas、Toolbar、Sidebar、Panel Inspector、Export、Preflight 组件和独立 TS 核心模块。
- 工程状态由 reducer 管理；图像、布局、标签、出版参数均有显式类型。
- “投稿准备”六个一级工作区为：总览、论文准备、科研组图、投稿材料、期刊匹配、投稿前检查。
- Figure Composer 图片本体默认浏览器本地处理，工程与资源存入 IndexedDB；不未经设计上传 Supabase。
- Figure project 可关联 Manuscript Draft，仅复用既有 `figure_count` 字段同步工程数量，不引入数据库迁移。

## 第二轮：科研排版正确性

- 96 DPI 逻辑坐标与视图缩放分离。
- 每个面板记录原始像素尺寸、原始宽高比和 `lockAspectRatio`。
- 支持自由 X / Y / W / H、rowSpan / colSpan、量化行列和 A 大图 + B/C 非均匀布局。
- 支持多选、六向对齐、横纵等间距、边缘/中心/统一间距吸附和可见参考线。
- 支持自动包裹画布，避免强制固定大面积空白。
- 支持 mm / cm / inch、DPI 到输出像素换算。
- 支持 PNG/JPG/WEBP/TIFF/PDF/SVG，SVG 使用 `viewBox` 与 `preserveAspectRatio` 保留正确比例语义。

## 第三轮：UI / UX

- 科研组图同时有投稿准备顶部高优先级入口和一级“科研组图”导航入口。
- 桌面工作区采用左侧工程/图层、中间大 Canvas、右侧检查器/导出/预检的三栏结构。
- 控件保持高信息密度，避免营销式大卡片、重渐变和纯黑暗色背景。
- Luminous 与 Luminous X 均必须通过现有浏览器回归。
- 1366 / 1440 / 1920 等桌面宽度应保持可操作；窄屏与移动端允许降级，但不得页面崩坏或横向结构失控。

## 第四轮：工程质量

- `npm run verify` 必须通过 Figure Composer、online-only、隐私、期刊、附件生命周期、TypeScript 和生产构建门禁。
- 资源对象 URL 有明确回收路径，大像素画布有上限保护，PDF/TIFF 加载失败有用户可见错误。
- 最终离线版冻结后，`offline.html`、`src/offline.tsx`、离线 Vite 配置、持续离线 Release workflow 和离线构建检查不再参与主开发链。
- 旧视觉回归改用 `tests/visual` 专用兼容壳，不恢复产品离线入口。

## 第五轮：发布与回归

合并前与发布后必须取得以下自动化证据：

- Check
- Verify Online Build
- Verify Luminous interfaces and onboarding
- Verify UI Geometry Contract
- Capture Visual Review
- Update Documentation Screenshots
- Verify Submission Card Actions
- 示例数据隐私检查
- TypeScript 和生产构建
- 最终离线 Release `v2.0.1-offline-final`，冻结源码 SHA `830cd645ee74f33ab41fd28e4bbafcd1fee31841`
- GitHub Release `v2.1.0`
- Deploy to GitHub Pages
- 线上 `build-info.json` SHA 与最终 main 合并 SHA 完全一致

只有关键门禁通过、PR 合并、v2.1.0 Release 成功且线上 SHA 完成反查后，v2.1.0 才能标记为正式上线。
