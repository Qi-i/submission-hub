# v2.1.0 Release Audit

发布日期：2026-08-20

本文件记录 Submission Hub v2.1.0 的发布门禁。结论必须以 GitHub Actions、Release 和线上 SHA 的实际结果为准；尚未完成的检查不得提前标记为通过。

## 第一轮：功能与数据

- 科研组图作为在线投稿准备的独立工具工作区，不改变原有五个投稿准备业务入口。
- 组图功能不写入投稿、期刊、选题或草稿数据表，不引入数据库迁移。
- 图片默认只在浏览器内处理；PDF/TIFF 的兼容库按需加载。
- 最终离线版使用冻结源码 SHA `830cd645ee74f33ab41fd28e4bbafcd1fee31841`，与 v2.1.0 在线功能隔离。
- 历史在线数据、备份兼容逻辑和 Supabase 表结构保持不变。

## 第二轮：界面、响应式与代码

- 科研组图默认子图标签为 `(a)` 形式，字体 Times New Roman。
- 工作区支持桌面双栏、平板单栏、移动端紧凑布局及暗色主题。
- 保持 Luminous 与 Luminous X 主导航语义一致。
- 科研组图样式使用独立 scoped stylesheet，不建立新的 final/hotfix 尾部覆盖链。
- `app-styles.ts` 移除本轮发现的重复导入。
- 在线构建链删除离线 HTML、离线 Vite、离线隔离检查和持续离线 Release 入口。

## 第三轮：最终门禁

合并前与发布后必须取得以下自动化证据：

- Check
- Verify Online Build
- Verify Luminous interfaces and onboarding
- Verify UI Geometry Contract
- Capture Visual Review
- Update Documentation Screenshots
- Verify Submission Card Actions
- 示例数据隐私检查
- TypeScript 和生产构建
- GitHub Release `v2.1.0`
- Deploy to GitHub Pages
- 线上 `build-info.json` SHA 与最终 main 合并 SHA 完全一致

只有上述关键门禁通过，且线上 SHA 完成反查后，v2.1.0 才能标记为正式上线。
