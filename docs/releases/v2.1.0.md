# Submission Hub v2.1.0

发布日期：2026-08-20

## 本次更新

### 科研组图迁移

- 将 FigMergeStudio 的核心科研组图工作流重构为 Submission Hub 原生 React/TypeScript 模块，而不是 iframe 或独立 HTML 嵌入。
- 在在线版“投稿准备”顶部增加高优先级科研组图入口，同时保留既有五个业务入口：总览、选题池、草稿准备、期刊库、期刊比较。
- 支持 PNG、JPG、WEBP、SVG、TIFF 和 PDF 导入。
- 支持自动网格、自由拖拽、图层顺序、缩放、吸附对齐、自由文本和图片完整显示/填满图框。
- 子图标签默认使用 `(a), (b), (c)`，默认字体 Times New Roman，并保留字体、字号、位置和偏移控制。
- 支持 150–1200 DPI，以及 PNG、JPG、WEBP、TIFF、PDF、SVG 导出。
- 图像处理默认在当前浏览器完成；PDF/TIFF 兼容组件仅在用户使用相应格式时按需加载。
- 增加第三方来源和 MIT 许可归属文件 `THIRD_PARTY_NOTICES.md`。

### 最终离线版冻结

- 以 `830cd645ee74f33ab41fd28e4bbafcd1fee31841` 作为最后离线版源码基线。
- 单独创建不可覆盖的 `offline-final-v2.0.0` Release，避免修改历史 `v2.0.0` 标签和版本链。
- 从 v2.1.0 开始，主分支不再持续构建、验证或发布离线 HTML。
- 移除离线 Vite 入口、离线 HTML 入口、离线构建检查和持续离线 Release 工作流。

### 在线专用发布链

- `npm run verify` 改为验证在线应用和在线维护契约。
- `Verify Online and Offline Builds` 重构为 `Verify Online Build`。
- 新增 `Release Online Edition`，在版本发布时运行完整在线验证，并生成可部署 Web 快照及 SHA256 校验文件。
- GitHub Pages 发布仍独立执行；只有线上 `build-info.json` 的 SHA 与本次 main 合并 SHA 一致，才视为完成上线。

### UI 与代码清理

- 科研组图使用独立 scoped stylesheet，不新增 `final/hotfix` 叠加式覆盖文件。
- 清理 `app-styles.ts` 中重复加载的样式/交互模块引用。
- 为科研组图补充桌面、窄屏、移动端和暗色主题布局。
- 保持 Luminous 与 Luminous X 的既有主导航与投稿准备五入口不变。
