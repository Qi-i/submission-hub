# Submission Hub v2.1.0

发布日期：2026-08-20

## 本次更新

### 投稿准备与科研组图重构

- 将 FigMergeStudio 的科研组图核心能力重构为 Submission Hub 原生 React + TypeScript Figure Composer，不使用 iframe，也不复制独立 HTML。
- “投稿准备”重构为六个一级工作区：**总览、论文准备、科研组图、投稿材料、期刊匹配、投稿前检查**；原有选题、草稿、期刊库和期刊比较能力继续保留在对应工作流中。
- 科研组图同时保留投稿准备顶部快捷入口，进入后使用独立桌面工作区，而不是普通表单卡片。
- 支持 PNG、JPG、WEBP、SVG、TIFF 和 PDF 导入。
- 支持自动网格、量化行列、自由拖拽、A 大图 + B/C 非均匀布局，以及 rowSpan / colSpan。
- 每个子图记录原始像素尺寸和宽高比；支持锁定原始比例、自由宽高和 X / Y / W / H 精确输入。
- 支持 Ctrl/Cmd 与 Shift 多选、六向对齐、横向/纵向等间距、边缘/中心/统一图间距吸附和可见参考线。
- 子图标签默认 `(a), (b), (c)` 与 Times New Roman，可调整字体、字号、字重、位置、颜色和 X/Y 偏移。
- 支持自由文本、边框、图层顺序、视图缩放和自动包裹画布；视图缩放不改变逻辑图件尺寸。
- 使用 96 DPI 逻辑坐标体系，支持 mm / cm / inch 出版尺寸和 DPI 到输出像素换算。
- 支持 PNG、JPG、WEBP、TIFF、PDF 和 SVG 导出；SVG 使用明确 `viewBox` 与 `preserveAspectRatio` 保持比例语义。
- Figure project 可关联 Manuscript Draft，保存/删除工程后同步草稿 `figure_count`。
- 投稿前预检覆盖低分辨率、越界、重叠、非法拉伸和缺少图题/图注等问题。
- 图片本体默认保存在当前浏览器 IndexedDB；不会未经设计自动上传 Supabase。
- 第三方来源和 MIT 许可归属见 `THIRD_PARTY_NOTICES.md`。

### 最终离线版冻结

- 以 `830cd645ee74f33ab41fd28e4bbafcd1fee31841` 作为最终离线版源码基线。
- 发布独立不可覆盖的 `v2.0.1-offline-final` Release，不修改历史 `v2.0.0` 标签。
- Release 继续提供 `submission-hub-offline.html` 和 SHA256 校验文件。
- 最终离线构建已通过完整旧版验证、隐私检查、单 HTML/云代码隔离检查；发布资产与冻结源码重构建结果 SHA256 一致。
- 从 v2.1.0 开始，主开发链不再持续构建、验证或发布新的离线 HTML。
- 移除离线 Vite/HTML/React 入口、离线构建检查和持续离线 Release 工作流；历史离线 Release 保留供旧用户下载。

### 在线专用发布链

- `npm run verify` 改为验证在线应用、Figure Composer 和在线维护契约。
- `Verify Online and Offline Builds` 重构为 `Verify Online Build`。
- 新增 `Release Online Edition`：发布前运行完整在线验证，并生成可部署 Web 快照和 SHA256 校验文件。
- GitHub Pages 发布保持独立；只有线上 `build-info.json` 的 SHA 与本次 `main` 合并 SHA 完全一致，才视为完成上线。

### UI 与工程质量

- Figure Composer 拆分为 Canvas、Toolbar、Sidebar、Panel Inspector、Export、Preflight 组件，以及独立 geometry/layout/snapping/import/project/validation/export TypeScript 模块。
- 使用 reducer 管理工程状态，避免单文件全局状态和大量 DOM id 操作。
- Figure Composer 使用一个 scoped stylesheet，提供高信息密度桌面布局、蓝灰暗色主题以及窄屏/移动端降级。
- 现有 Luminous / Luminous X 主导航和投稿、期刊、统计业务继续使用相同数据与业务逻辑。
- 旧视觉测试壳迁移到 `tests/visual` 专用入口，不恢复 `src/offline.tsx` 产品运行链。
