# Submission Hub v1.5.0 更新说明

发布日期：2026-07-25

v1.5.0 汇总 v1.4.0 之后完成的界面统一、投稿准备重构、期刊资料增强、私有附件、账户管理和自动验证改进。在线版与离线版共享核心组件、数据模型和显示逻辑。

## 1. Luminous 与 Luminous X

- Luminous 采用顶部导航和横向页面结构。
- Luminous X 采用固定左侧栏和顶部状态控制区。
- 两套界面完整覆盖投稿准备、投稿管理、个人统计和后台管理。
- 两套界面共享投稿、期刊、选题、草稿、账户偏好和备份数据。
- 页面右侧边缘提供界面与主题切换，在线账户同步选择结果。
- 桌面亮色、桌面暗色、移动端和离线版纳入同一套视觉回归。

## 2. 投稿准备工作区

- 总览、研究选题池、草稿准备、期刊库和期刊比较组成统一工作区。
- 系统记忆最近打开的主页面、投稿准备子页面和投稿管理视图。
- “草稿推进”与“收藏期刊”保持同级、等高和独立滚动。
- 新建草稿与收藏期刊入口固定在对应页面的顶部操作区。
- 论文准备助手与选题推进记录排序、折叠和位置状态。
- 草稿卡片压缩低价值说明，提高首屏完整记录数量。

## 3. 投稿管理

- 投稿管理提供工作流、看板和按期刊三种视图。
- 期刊名作为卡片头部主要信息，长期刊名使用缩小字号和两行显示。
- 主状态、后台原始状态、出版入口、作者、时长和下一步形成固定层级。
- 已出版链接与 DOI 合并为单一入口。
- 未知审稿指标、APC 和空元数据不保留空白框。
- 中文投稿状态映射到统一主状态，同时保留后台原文。
- 时间线计算节点间隔、首投累计天数和最后更新距今。

## 4. 私有附件

- Cloudflare R2 作为在线附件主存储。
- 私有 Supabase Storage 作为回退存储。
- 浏览器内预览覆盖 PDF、图片、DOCX、XLS、XLSX、CSV、PPTX 和文本文件。
- 附件入口显示 PDF、Word、表格、PPT、回复、检索、见刊和录用等可读标识。
- 替换、移除、取消编辑和删除稿件执行对应的对象清理。
- 离线版继续使用本地记录和 JSON 备份，不写入云端存储。

## 5. 期刊库与选刊资料

- 期刊库使用高密度多列卡片，减少卡片宽度、内边距、指标块和阴影。
- 长期刊名、分区标签、底部链接栏和多列对齐纳入几何检查。
- 中文期刊名位于英文名下方并突出显示。
- 缩写仅显示简洁、学界可识别的形式。
- 英文简介与中文简介翻译分字段保存。
- 选刊标签和选刊备注进入检索、卡片和期刊比较。
- EasyScholar 标签按期刊独立控制外显；中科院基础版和升级版小类默认隐藏。
- `012_journal_selection_metadata.sql` 保存中文名、缩写、中文简介、选刊标签和选刊备注。

## 6. 审稿指标与 OA / APC

- “获取审稿周期”读取期刊官网、作者指南、投稿入口和指定来源页面。
- Elsevier 与 ScienceDirect 期刊主页自动转换为 `/about/insights` 地址。
- 解析结果包含首轮决定、投稿至接收周期和接收率。
- 来源地址与更新时间跟随指标保存。
- 混合 OA 分开显示订阅发表和开放获取路径。
- APC 保留原始金额与币种，人民币金额作为参考换算。
- 年发文量、自引率和审稿周期保存来源、统计口径与更新时间。

## 7. 登录与个人资料

- GitHub OAuth、邮箱密码和邮箱链接使用 GitHub Pages 子路径回跳地址。
- GitHub 身份与邮箱登录进入同一 Supabase 用户账户。
- 账户设置管理密码、显示名和头像。
- 登录回跳展示身份绑定结果。
- 界面、主题和引导状态随在线账户同步。
- 离线偏好保存在当前浏览器。

## 8. 使用顺序

1. 在研究选题池建立选题记录。
2. 将选题转为草稿并补充摘要、提纲、作者、图表和检查项。
3. 在期刊库建立目标期刊资料并填写双语信息、分区、OA、APC、速度和备注。
4. 在期刊比较中确定主投期刊。
5. 正式投出后将草稿转入投稿管理。
6. 按时间顺序新增编辑处理、外审、决定、修回和再次外审节点。
7. 录用后填写 DOI、出版链接、卷期页码和引用格式。
8. 归档录用通知、校样、检索证明和见刊文件。

## 9. 兼容性与隐私

- 新字段对旧投稿、旧期刊和旧备份保持兼容。
- 离线版保持单 HTML、本地存储和无 Supabase 依赖。
- 示例数据、README 截图和视觉测试全部使用虚构内容。
- 服务密钥不进入前端、截图、日志、README 和仓库。
- 文档截图覆盖 Luminous 与 Luminous X 的四个主页面。
