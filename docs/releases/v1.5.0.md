# Submission Hub v1.5.0 更新说明

发布日期：2026-07-25

v1.5.0 汇总了 v1.4.0 之后完成的界面统一、投稿准备重构、期刊资料增强、私有附件、账户管理和自动验证改进。在线版与离线版继续共享核心组件、数据模型和显示逻辑。

## 1. 界面与导航

- 保留 Luminous 与 Luminous X 两套界面，移除旧 Classic 入口。
- 统一投稿准备、投稿管理、个人统计和后台管理的页面边距、最大宽度、导航结构和标题层级。
- 修复 Luminous 四个页面导航位置不一致、中文导航换行和控制区挤压问题。
- Luminous X 使用固定侧栏和紧凑顶部控制栏，支持工作流、看板和按期刊视图。
- 亮色页面改用中性浅底，避免整页蓝色渐变与内容色块混淆。
- 两套界面均覆盖桌面亮色、桌面暗色、移动端和离线版。

## 2. 投稿准备工作区

- 总览、选题池、草稿准备、期刊库和期刊比较统一为紧凑工作区。
- 记忆最近打开的主页面、投稿准备子页面和 Luminous X 投稿管理视图。
- “草稿推进”与“收藏期刊”保持同级、等高和独立滚动。
- 新建草稿、收藏期刊等真实操作入口在对应页面保持可见。
- 论文准备助手与选题推进支持排序、折叠和本地状态保存。
- 草稿卡片压缩低价值说明，提高首屏完整记录数量。

## 3. 投稿管理与附件

- 期刊名作为卡片头部主要信息，支持长期刊名缩小字号和两行显示。
- 主状态、后台原始状态、出版入口、作者、时长和下一步形成明确层级。
- 已出版链接与 DOI 合并为一个紧凑入口，避免重复占位。
- 未知审稿指标、APC 和空元数据不再保留空白框。
- 附件类型使用 PDF、Word、表格、PPT、回复、检索、见刊、录用等可读标识。
- 在线附件优先存入私有 Cloudflare R2，失败时回退到私有 Supabase Storage。
- 支持 PDF、图片、DOCX、XLS/XLSX/CSV、PPTX 和文本文件的浏览器内预览。
- 替换、移除、取消编辑和删除稿件时执行对应的私有文件生命周期清理。

## 4. 期刊库与选刊信息

- 期刊库改为高密度多列卡片，桌面端减少卡片宽度、内边距、指标块和阴影。
- 修复长期刊名截断、分区标签裁切、重复链接、未知指标残留和底部链接栏不齐。
- 新增中文期刊名、缩写、中文简介翻译、选刊标签和选刊备注。
- 中文名位于英文名下方并突出显示；缩写仅在简洁且具有识别价值时外显。
- EasyScholar 标签可按期刊独立选择卡片外显；中科院基础版和升级版小类默认隐藏。
- 新字段同步支持在线数据库、离线存储、备份导入、全文检索和期刊比较。
- 数据库新增 `012_journal_selection_metadata.sql` 迁移。

## 5. 审稿周期与 OA / APC

- 新增“获取审稿周期”，可从期刊官网、作者指南、投稿入口或指定来源页面读取公开指标。
- 支持 Elsevier / ScienceDirect 期刊主页自动推导 `/about/insights` 页面。
- 可解析首轮决定、投稿至接收总周期和接收率，同时保留来源地址并提示人工核验口径。
- 混合 OA 分开显示“订阅发表｜无 APC”和“开放获取｜原币 APC ≈ 人民币参考价”。
- APC 保留原始金额与币种，人民币仅为参考换算。
- 年发文量、自引率和审稿周期均保留来源、统计口径与更新时间。

## 6. 登录与个人资料

- GitHub OAuth、邮箱密码和邮箱链接登录使用正确的 GitHub Pages 子路径回跳地址。
- 支持为 OAuth 账户设置密码，或为邮箱账户绑定 GitHub 身份。
- 支持编辑显示名、上传或移除头像，并同步到用户资料与 Auth metadata。
- 登录回跳后显示明确的身份绑定成功或失败反馈。
- 界面、主题与引导完成状态可随在线账户同步；离线偏好继续保存在本机。

## 7. 兼容性与隐私

- 新字段对旧投稿、旧期刊和旧备份保持可选兼容，不会清空未知或无法识别的数据。
- 离线版继续保持单 HTML、本地存储和无 Supabase 依赖。
- 示例数据、README 截图和视觉测试均使用虚构内容。
- 服务密钥不得进入前端、截图、日志、README 或仓库。
